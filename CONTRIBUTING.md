# Contributing / المساهمة

Thank you for improving Arabic UI Components. Keep changes dependency-free unless there is a compelling, documented reason. Preserve RTL behavior, keyboard access, visible focus states, responsive layouts, and semantic HTML. Add or update tests for JavaScript behavior, run `npm test` and `npm run check`, and keep README examples aligned with the implementation. Use focused commits and describe visual/accessibility impact in pull requests.

شكرًا لمساهمتك في Arabic UI Components. حافظ على خفة المشروع وعدم إضافة اعتماديات إلا لسبب موثق، وعلى دعم RTL ولوحة المفاتيح وحالات التركيز والتجاوب وHTML الدلالي. حدّث الاختبارات عند تغيير JavaScript، وشغّل `npm test` و`npm run check`، واجعل أمثلة README مطابقة للتنفيذ. يُفضّل أن تكون التغييرات مركزة وواضحة.
