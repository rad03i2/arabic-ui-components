# Arabic UI Components

Reusable front-end components designed for Arabic right-to-left interfaces.

## Components

- RTL navigation bar
- Statistic cards
- Arabic form fields
- Alert messages
- Responsive dashboard layout

## Stack

`HTML` · `CSS` · `JavaScript` · `RTL Design`

## Run

Open `index.html` directly in your browser.
